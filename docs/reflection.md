Reflection

In this lab, I learned how to use GitHub to organize and manage a project. I learned how to create issues, use branches, make commits, and merge changes using pull requests. I also learned that project planning makes the work more organized because each task can be separated and tracked.
The most challenging part for me was working with branches and making sure the changes were merged correctly. It was also fun to see how the project changed after each commit. If I had more time, I would improve the project by adding more planets, more information, and images to make it more useful and interesting.
